# Merge Sorted Arrays Project

This project implements a custom `merge` function in TypeScript to combine three sorted arrays into a single ascending sorted array, utilizing a multiple-pointer approach without using any built-in sorting functions.

## Prerequisites
- Node.js (v14 or higher)
- npm (Node Package Manager)

## Setup & Installation
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the required dependencies (TypeScript and Jest) by running:
   ```bash
   npm install


# Execution & Testing

   ```Bash
